# Задание 1

## Задача 14

### Текст задачи

Оставить в списке только первые вхождения одинаковых элементов.

### Алгоритм решения

Используется `List<int>` и вспомогательное множество `HashSet<int>`.

1. Пользователь вводит элементы списка в одну строку через пробел. Метод `ReadIntList` разбивает строку и проверяет, что каждый элемент — целое число. Если нет, выводится сообщение и ввод повторяется.
2. Создаём пустой `HashSet<int> seen` — в нём хранятся числа, которые уже встречались.
3. Заводим два индекса: `readIndex` — по какому элементу идём, `writeIndex` — куда записывать следующий «нужный» элемент.
4. Идём по списку слева направо. Для каждого элемента пробуем добавить его в `seen`:
   - метод `Add` вернул `true` — число встретилось впервые, записываем его в `list[writeIndex]` и увеличиваем `writeIndex`;
   - вернул `false` — такое число уже было, пропускаем.
5. После цикла все нужные элементы лежат в начале списка, а «хвост» с повторами не нужен. Удаляем его через `RemoveRange(writeIndex, list.Count - writeIndex)`.

Так список проходится один раз, а проверка «было ли число раньше» в `HashSet` выполняется быстро. Если передали `null`, метод бросает `ArgumentNullException`.

### Тестирование

| Ввод | Результат |
|---|---|
| `1 2 2 3 1 4 3` | `1, 2, 3, 4` |
| `5 5 5 5` | `5` |
| `1 2 3` (повторов нет) | `1, 2, 3` |
| `1 a 3` | сообщение «a — не целое число», ввод повторяется |
| пустая строка | сообщение «Список не может быть пустым» |

# Задание 2

## Задача 15

### Текст задачи

Если у элемента со значением E «соседи» не равны, заменить их на элемент F.

### Алгоритм решения

Используется `LinkedList<int>`.

1. Вводим элементы списка (так же через `ReadIntList`), создаём из них `LinkedList<int>`, затем вводим значения `E` и `F`.
2. Берём первый узел списка `list.First` и идём по узлам, пока узел не станет `null`.
3. Перед проверкой запоминаем следующий узел в переменную `next`, чтобы спокойно менять текущий и потом перейти дальше.
4. Если значение узла равно `E`:
   - проверяем, что у узла есть и предыдущий, и следующий (`Previous != null` и `Next != null`), потому что у крайних элементов нет двух соседей;
   - сравниваем значения соседей `node.Previous.Value` и `node.Next.Value`;
   - если соседи **не равны**, записываем в узел значение `F`.
5. Переходим к `next` и повторяем до конца списка.

### Тестирование

Для `E = 2`, `F = 9`:

| Ввод | Результат |
|---|---|
| `1 2 3 2 5` | `1, 9, 3, 9, 5` (у обеих двоек соседи разные) |
| `4 2 4` | `4, 2, 4` (соседи равны — ничего не меняется) |
| `2 1 3` | `2, 1, 3` (у первого элемента нет левого соседа) |

# Задание 3

## Задача 14

### Текст задачи

Есть перечень иностранных языков. Работники фирмы могут знать некоторые из них. Для каждого работника известно, какие языки он знает. Определить для каждого языка, какие из них знает каждый из работников, какие — хотя бы один из работников, и какие — никто из работников.

### Алгоритм решения

Используются `HashSet<string>` и один `Dictionary<string, int>`.

1. Вводим количество языков и сами названия. Все языки кладём в множество `allLanguages` (дубликаты отсекаются автоматически).
2. Вводим количество работников. Для каждого работника — сколько языков он знает и сами языки. Каждый работник хранится как отдельный `HashSet<string>`, а все они лежат в `List<HashSet<string>>`. Если введён язык, которого нет в перечне, он пропускается с сообщением.
3. Дальше работает метод `AnalyzeLanguages`. Он возвращает три множества: `knownByAll`, `knownBySome`, `knownByNone`.
4. Если работников нет вообще, все языки попадают в «не знает никто».
5. Иначе считаем в словаре `counts`, сколько работников знает каждый язык: идём по всем работникам и по всем их языкам и увеличиваем счётчик.
6. Запоминаем `totalWorkers` — общее число работников и идём по всем языкам из перечня:
   - языка нет в `counts` — его не знает никто, кладём в `knownByNone`;
   - счётчик равен `totalWorkers` — знают все, кладём в `knownByAll`;
   - счётчик меньше `totalWorkers` — знает только часть работников, кладём в `knownBySome`.
7. Результат выводится через `FormatSet`: если множество пустое, печатается «(пусто)».

### Тестирование

Перечень: Английский, Немецкий, Французский, Китайский. Два работника: первый знает Английский и Немецкий, второй — Английский и Французский.

| Категория | Результат |
|---|---|
| Знают все работники | Английский |
| Знает не все, но кто-то знает | Немецкий, Французский |
| Не знает никто | Китайский |

Дополнительно проверено: ввод языка не из перечня (пропускается), ввод нуля или отрицательного числа там, где нужно положительное (повторный запрос), работник, не знающий ни одного языка.

# Задание 4

## Задача 14

### Текст задачи

Файл содержит текст на русском языке. С каких букв начинаются слова?

### Алгоритм решения

Используется `HashSet<char>`, чтобы каждая буква хранилась один раз.

1. Пользователь вводит текст (непустую строку).
2. Метод `FirstLettersOfWords` делит текст на слова через `Split`, где разделителями считаются пробел, табуляция, перенос строки и знаки препинания (`. , ! ? ; : - — « » ( )`). Пустые фрагменты отбрасываются опцией `RemoveEmptyEntries`.
3. Создаём пустое множество `firstLetters`.
4. Для каждого слова берём первый символ `word[0]` и приводим его к нижнему регистру, чтобы «М» и «м» считались одной буквой.
5. Если символ — буква (`char.IsLetter`), добавляем его в множество. Цифры и прочие символы пропускаются.
6. Печатаем буквы через запятую.

В условии сказано «файл», но в программе текст вводится с клавиатуры, потому что файл по заданию нужен только в задании 5.

### Тестирование

| Ввод | Результат |
|---|---|
| `Мама мыла раму. Молоко стоит на столе!` | `м, р, с, н` |
| `Привет, мир!` | `п, м` |
| `123 abc` | `a` (цифры не буквы, `a` — латиница, но тоже буква) |

# Задание 5

## Задача 14

### Текст задачи

Имеется список учеников разных школ, сдававших экзамен по информатике, с указанием их фамилии, имени, школы и набранного балла. Напишите программу, которая будет определять двух учеников школы № 50, которые лучше всех сдали информатику, и выводить на экран их фамилии и имена.

Если наибольший балл набрали более двух человек, нужно вывести только их количество. Если наибольший балл набрал один человек, а следующий балл набрало несколько человек, нужно вывести только фамилию и имя лучшего. Известно, что информатику сдавали не менее 5 учеников школы № 50.

На вход программе в первой строке подается количество учеников в списке N. В каждой из последующих N строк находится информация в следующем формате:

`<Фамилия> <Имя> <Школа> <Балл>`

где `<Фамилия>` — строка не более чем из 20 символов без пробелов, `<Имя>` — строка не более чем из 20 символов без пробелов, `<Школа>` — целое число от 1 до 99, `<Балл>` — целое число от 1 до 100.

Пример входной строки: `Иванов Сергей 50 87`

Пример выходных данных, когда найдено два лучших:

```
Иванов Сергей
Сергеев Иван
```

Если больше двух учеников набрали высший балл, программа выводит их количество, например `8`. Если высший балл набрал один человек, а следующий балл набрало несколько человек, выводится только фамилия и имя лучшего.

### Алгоритм решения

Исходные данные хранятся в текстовом файле `students.txt`, который создаётся отдельным методом `CreateStudentsFile`.

1. В `Task5` определяем путь к файлу `students.txt` в папке программы. Если файла нет, вызываем `CreateStudentsFile`, который записывает в файл тестовые данные: в первой строке `N`, дальше строки с учениками.
2. Метод `FindTopTwoSchool50FromFile` читает файл через `File.ReadAllLines`. Перед обработкой проверяется:
   - файл существует и не пустой;
   - первая строка — целое положительное число `N`;
   - строк с данными не меньше `N`.
3. Каждая строка делится по пробелам. Если частей не четыре или школа и балл не числа, строка пропускается. Остальные превращаются в объекты вспомогательного класса `Student` (фамилия, имя, школа, балл) и складываются в список.
4. Метод `FindTopTwo` за один проход по списку находит лучший и второй по величине баллы среди учеников школы №50. Заводим `max1`, `max2` и два списка: `top1` (все с лучшим баллом) и `top2` (все со вторым баллом). Для каждого ученика из школы 50:
   - балл больше `max1` — старый лучший становится вторым (`max2 = max1`, `top2` копируется из `top1`), а ученик становится единственным в новом `top1`;
   - балл равен `max1` — добавляем ученика в `top1`;
   - балл больше `max2` — ученик начинает новый `top2`;
   - балл равен `max2` — добавляем его в `top2`.
5. Выводим результат:
   - в `top1` больше одного человека — выводим их количество;
   - в `top1` один человек и во `top2` больше одного — выводим только лучшего;
   - в `top1` один и во `top2` один — выводим обоих;
   - в `top1` один и `top2` пустой — выводим только лучшего;
   - `top1` пуст — сообщение, что учеников школы №50 нет.

### Тестирование

Файл `students.txt` по умолчанию:

```
8
Иванов Сергей 50 87
Сергеев Иван 50 95
Петров Петр 50 95
Сидоров Сидор 50 87
Смирнов Алексей 50 75
Кузнецов Олег 49 99
Попов Дмитрий 50 90
Васильев Игорь 50 85
```

Ученик школы 49 (Кузнецов, 99) в расчёт не берётся. Для проверки остальных веток файл можно менять вручную:

| Ситуация в файле | Что выводится |
|---|---|
| несколько человек с лучшим баллом | их количество |
| один лучший, у второго балла несколько человек | только лучший |
| один лучший и один второй | оба |
| нет учеников школы 50 | сообщение «Нет учеников из школы №50» |
| файл пустой или удалён вручную | сообщение об ошибке / файл создаётся заново |

# Задание 6

## Задача 14

### Текст задачи

Класс `Time`, поля: `byte hours`, `byte minutes`. Метод: вычитание времени (величины типа `Time`) из объекта типа `Time` (учесть, что возможен переход в предыдущие сутки). Результат должен быть типа `Time`.

### Алгоритм решения

Класс `Time` лежит в отдельном проекте `Lab4Time`.

**Поля и свойства.** Два приватных поля `_hours` и `_minutes` типа `byte`. Доступ к ним — через свойства `Hours` и `Minutes`. В `set` стоит проверка: часы не больше 23, минуты не больше 59, иначе бросается `ArgumentOutOfRangeException`.

**Конструкторы.** Конструктор без параметров создаёт время `00:00`. Конструктор с параметрами `(byte hours, byte minutes)` записывает значения через свойства, поэтому проверка работает и там.

**ToString().** Выводит время в формате `ЧЧ:ММ` с ведущими нулями (`{_hours:D2}:{_minutes:D2}`).

**Метод `Subtract(Time other)`:**

1. Если `other` равен `null`, бросаем `ArgumentNullException`.
2. Переводим оба времени в минуты: `часы * 60 + минуты`.
3. Вычитаем: `diff = минуты_этого − минуты_другого`.
4. Если `diff` получился отрицательным, значит переход в предыдущие сутки — прибавляем `24 * 60 = 1440` минут.
5. Переводим обратно: часы — `diff / 60`, минуты — `diff % 60`. Возвращаем новый объект `Time`.

**Проверка ввода в программе.** Метод `ReadTime` просит часы и минуты и принимает только числа в диапазонах 0–23 и 0–59. Если ввели что-то другое, вопрос повторяется. В главном меню первый пункт запускает вычитание.

### Тестирование

| Уменьшаемое | Вычитаемое | Результат |
|---|---|---|
| 10:30 | 08:15 | 02:15 |
| 02:00 | 03:30 | 22:30 (переход в предыдущие сутки) |
| 05:45 | 05:45 | 00:00 |

Также проверен ввод некорректных данных (буквы, часы 25, минуты 60) — программа просит ввести заново.

# Задание 7

## Задача 14

### Текст задачи

К классу `Time` из задания 6 добавить перегруженные операции:

- унарная `--` — вычитание минуты из объекта типа `Time`;
- приведение типа `byte` (явная) — результатом является количество часов (минуты отбрасываются);
- приведение типа `bool` (неявная) — результатом является `true`, если часы и минуты не равны нулю, и `false` в противном случае;
- бинарная `+`: `Time t`, беззнаковое целое число (лево- и правосторонние операции) — добавление минут к времени;
- бинарная `+`: `Time t1`, `Time t2` — сложить два времени.

### Алгоритм решения

Все операторы добавлены в тот же класс `Time`. Для сложения с минутами написан приватный вспомогательный метод `AddMinutes(Time time, int minutes)`.

**`AddMinutes`:**

1. Проверяем, что `time` не `null`.
2. Переводим время в минуты и прибавляем `minutes` (может быть и отрицательным).
3. Приводим сумму к диапазону от 0 до 1439: `((total % 1440) + 1440) % 1440`. Дополнительное `+ 1440` нужно, чтобы остаток от деления отрицательного числа тоже стал положительным.
4. Переводим в часы и минуты, создаём новый `Time`.

**Операторы:**

- `--` — вызывает `AddMinutes(time, -1)`. Например, `00:00` после `--` станет `23:59`. Оператор `++` (`AddMinutes(time, 1)`) тоже реализован, на `23:59` он даёт `00:00`.
- `explicit operator byte` — возвращает `_hours`. Явный, значит, использовать надо так: `(byte)time`.
- `implicit operator bool` — возвращает `true`, если часы или минуты не равны нулю, то есть время не `00:00`. Неявный, значит, можно написать `bool flag = time;` или использовать `time` в условии.
- `operator +(Time, uint)` и `operator +(uint, Time)` — оба вызывают `AddMinutes`, поэтому `time + 90` и `90 + time` дают одинаковый результат (левосторонняя и правосторонняя операции).
- `operator +(Time, Time)` — складываем минуты обоих времён, берём остаток от деления на 1440 (чтобы сумма не вышла за сутки) и переводим обратно в часы и минуты.

Во всех операторах есть проверка на `null`.

**Тестирование в программе.** Главное меню проекта сделано в цикле, пока пользователь не выберет `0`:

1. Вычитание `Time` из `Time` (задание 6)
2. Операторы `++` и `--`
3. Приведение к `byte`
4. Приведение к `bool`
5. `Time + uint` и `uint + Time`
6. `Time + Time`

Все числа вводятся с проверкой, количество минут должно быть неотрицательным.

### Тестирование

| Операция | Данные | Результат |
|---|---|---|
| `--` | 10:00 | 09:59 |
| `--` | 00:00 | 23:59 |
| `(byte)time` | 14:35 | 14 |
| `bool` | 00:00 | False |
| `bool` | 00:01 | True |
| `Time + uint` | 22:30 + 90 | 00:00 |
| `uint + Time` | 90 + 22:30 | 00:00 |
| `Time + uint` | 22:30 + 1500 | 23:30 |
| `Time + Time` | 15:40 + 10:30 | 02:10 |
